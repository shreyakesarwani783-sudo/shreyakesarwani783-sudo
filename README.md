### 🌿 2. Plant Disease Classification

> Deep Learning · Computer Vision · Image Classification

A CNN-based project for classifying plant leaf images into disease categories using the PlantVillage dataset.

**Tech stack**

`Python` `CNN` `Deep Learning` `Image Classification`

**Model details**
- Dataset: PlantVillage.
- Total images: 25,529.
- Training images: 20,428.
- Validation images: 5,101.
- Classes: 16.
- Input image dimensions: 128 × 128 × 3.
- Training duration: 15 epochs.
- Validation accuracy: **96.59%**.
- Validation loss: **0.1227**.

**Objective:** Explore how computer vision can help identify plant diseases from leaf images.
